# Assets from xml2rfc

`xml2rfc.css`, `metadata.min.js` and `xml2rfc.js` are copied unchanged from
xml2rfc 3.34.1 (https://github.com/ietf-tools/xml2rfc, directory
`xml2rfc/data`). They are the stylesheet and scripts that xml2rfc puts into
every HTML page it writes, and `xml2html` puts them into its pages the same
way, so that the two look and behave alike.
